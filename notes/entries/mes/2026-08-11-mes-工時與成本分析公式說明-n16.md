# 工時與成本分析公式說明

本文件說明本專案「工時與成本分析」頁面的資料來源、計算公式與注意事項。

## 1. 每道工序的標準工時

建立工令時，系統會根據途程資料計算並保存每道工序的標準分鐘：

```text
標準分鐘
= 準備時間
+（單位加工分鐘 × 工令數量）
+ 排隊時間
+ 搬運時間
```

分析頁顯示的標準時數為：

```text
標準時數 = 標準分鐘 ÷ 60
```

範例：

```text
準備時間 = 10 分鐘
單位加工時間 = 5 分鐘／雙
工令數量 = 100 雙
排隊時間 = 20 分鐘
搬運時間 = 10 分鐘

標準分鐘 = 10 +（5 × 100）+ 20 + 10
         = 540 分鐘

標準時數 = 540 ÷ 60
         = 9 小時
```

程式位置：`routing_demo/__init__.py` 的工令建立邏輯。

## 2. 工令總標準工時

```text
工令總標準工時
= 所有工序的標準分鐘合計 ÷ 60
```

範例：

```text
裁斷標準工時 = 5 小時
車縫標準工時 = 8 小時
包裝標準工時 = 7 小時

工令總標準工時 = 5 + 8 + 7
                 = 20 小時
```

## 3. 實際人工工時

實際人工工時來自 MES 的每筆報工資料。相同工序可以分批報工，系統會將工時累加：

```text
工序實際人工工時 = Σ 每筆 MES 報工的人工工時
```

工令層級的實際人工工時為：

```text
工令實際人工工時 = Σ 每道工序的實際人工工時
```

分析頁使用的是報工人員輸入的人工工時，不是直接以工序開始時間和完成時間的差值計算。

## 4. 實際設備工時

```text
工序實際設備工時 = Σ 每筆 MES 報工的設備工時
```

沒有使用設備的工序可以填入 `0`。

## 5. 工時差異

```text
工時差異 = 實際人工工時 − 標準時數
```

範例：

```text
標準時數 = 8 小時
實際人工工時 = 10 小時

工時差異 = 10 − 8
         = +2 小時
```

- 正數：實際人工工時超過標準，畫面顯示紅色。
- 零或負數：實際人工工時等於或少於標準，畫面顯示綠色。

## 6. 人工成本

```text
人工成本 = 實際人工工時 × 工作中心人工費率／小時
```

範例：

```text
實際人工工時 = 10 小時
人工費率 = $8／小時

人工成本 = 10 × 8
         = $80
```

## 7. 設備成本

```text
設備成本 = 實際設備工時 × 工作中心設備費率／小時
```

範例：

```text
實際設備工時 = 6 小時
設備費率 = $12／小時

設備成本 = 6 × 12
         = $72
```

## 8. 工序加工成本

若要取得單一工序的人工與設備合計成本，可使用：

```text
工序加工成本 = 人工成本 + 設備成本
```

工令的人工與設備總成本可使用：

```text
工令加工總成本
= Σ 每道工序的人工成本
+ Σ 每道工序的設備成本
```

目前分析畫面分別顯示人工成本和設備成本，沒有另外顯示加工總成本，也未納入材料、委外、管理或其他間接成本。

## 9. 生產效率

```text
效率 = 標準時數 ÷ 實際人工工時 × 100%
```

範例：

```text
標準時數 = 8 小時
實際人工工時 = 10 小時

效率 = 8 ÷ 10 × 100%
     = 80%
```

效率解讀：

- `100%`：實際人工工時剛好符合標準。
- 大於 `100%`：實際人工工時少於標準。
- 小於 `100%`：實際人工工時超過標準。
- 實際人工工時為 `0`：畫面顯示 `—`，避免除以零。

## 10. 最終良品與最終良率

最終良品是最後一道工序累計完成的良品數。

```text
最終良率
= 最後一道工序良品數 ÷ 工令數量 × 100%
```

範例：

```text
工令數量 = 1,000 雙
最後工序良品數 = 950 雙

最終良率 = 950 ÷ 1,000 × 100%
         = 95%
```

## 11. 數量流轉

第一道工序的投入數量來自工令數量；後續工序的投入數量來自前一道工序的累計良品：

```text
第一道工序投入數量 = 工令數量
後續工序投入數量 = 前一道工序良品數量
```

每次報工必須符合：

```text
本批投入數量 = 本批良品數量 + 本批不良數量
```

待處理數量為：

```text
待處理數量 = 投入數量 − 累計良品數量 − 累計不良數量
```

返工與報廢還必須符合：

```text
返工數量 + 報廢數量 ≤ 不良數量
```

## 12. MES 報工畫面的建議工時

報工畫面會依本次建議批量計算人工工時：

```text
本批建議工時
=（單位加工分鐘 × 本批數量 + 準備時間）÷ 60
```

如果工作中心有設備費率，設備工時預設使用相同的建議工時；沒有設備費率時預設為 `0`。

## 13. 目前程式的計算注意事項

### 13.1 標準工時使用原始工令數量

每道工序建立時，標準工時都是使用原始工令數量計算。若前一道工序產生不良品，後續工序的實際投入會減少，但已保存的標準工時不會跟著減少。

因此目前比較的是：

```text
原始工令計畫工時 VS 實際報工工時
```

而不是：

```text
依實際投入數量重算的標準工時 VS 實際報工工時
```

### 13.2 分批報工可能重複加入準備時間

工令標準工時只加入一次準備時間，但是報工畫面的每批建議工時都會加入完整準備時間。

如果同一道工序分成多批，而且每次都直接採用畫面建議值，累計實際工時可能包含多次準備時間，造成實際工時偏高。

是否合理取決於現場定義：

- 每批都需要重新準備：目前建議公式合理。
- 整張工令只準備一次：只有第一批應加入準備時間，後續批次不應重複加入。

## 14. 公式總表

| 指標 | 公式 |
|---|---|
| 工序標準分鐘 | 準備時間＋單位加工分鐘×工令數量＋排隊時間＋搬運時間 |
| 工序標準時數 | 工序標準分鐘÷60 |
| 工令總標準工時 | Σ 工序標準分鐘÷60 |
| 實際人工工時 | Σ MES 報工人工工時 |
| 實際設備工時 | Σ MES 報工設備工時 |
| 工時差異 | 實際人工工時−標準時數 |
| 人工成本 | 實際人工工時×人工費率／小時 |
| 設備成本 | 實際設備工時×設備費率／小時 |
| 工序加工成本 | 人工成本＋設備成本 |
| 效率 | 標準時數÷實際人工工時×100% |
| 最終良率 | 最後工序良品數÷工令數量×100% |
| 待處理數量 | 投入數量−累計良品−累計不良 |

## 15. 主要程式位置

- `routing_demo/__init__.py`：資料欄位、標準工時計算、MES 報工累加與數量流轉。
- `routing_demo/templates/analysis.html`：工時差異、人工成本、設備成本、效率及最終良率。
- `routing_demo/templates/order_detail.html`：MES 建議工時及報工輸入畫面。
