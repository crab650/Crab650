# ERP 學習筆記－虛件號（Phantom Item）與關鍵件號（Critical Item）

## 一、虛件號（Phantom Item）

### 什麼是虛件號？

虛件號（Phantom Item）是一種**具有品號及 BOM（物料清單），但沒有實體庫存、不建立工單、不入庫**的特殊物料。

它的主要用途是**整理 BOM 結構、提高 BOM 維護效率**。

> **一句話理解：**
>
> **虛件號是一個「邏輯上的組件」，而不是實際存在於倉庫的物料。**

---

## 虛件號的特性

| 項目     | 是否支援     |
| ------ | -------- |
| 有品號    | ✅        |
| 有 BOM  | ✅        |
| 有庫存    | ❌        |
| 建立工單   | ❌        |
| 半成品入庫  | ❌        |
| MRP 展開 | ✅ 直接展開子件 |

---

## 為什麼需要虛件號？

假設公司有三種產品：

* 登山車
* 公路車
* 電動車

三種車都共用同一組煞車零件。

若沒有虛件號：

```text
登山車
 ├─ 煞車把
 ├─ 煞車線
 └─ 煞車器

公路車
 ├─ 煞車把
 ├─ 煞車線
 └─ 煞車器

電動車
 ├─ 煞車把
 ├─ 煞車線
 └─ 煞車器
```

相同資料需要維護三次。

建立虛件號後：

```text
PH-BRAKE（虛件號）
 ├─ 煞車把
 ├─ 煞車線
 └─ 煞車器
```

各產品只需要引用：

```text
登山車
 ├─ 車架
 ├─ 前輪
 ├─ 後輪
 └─ PH-BRAKE
```

若日後更換煞車器，只需修改 **PH-BRAKE** 的 BOM，一次即可影響所有產品。

---

## MRP 如何處理虛件號？

假設：

```text
PH-BRAKE
 ├─ 煞車把
 ├─ 煞車線
 └─ 煞車器
```

若生產 100 台腳踏車：

MRP 不會產生：

```text
PH-BRAKE ×100
```

而是直接展開：

```text
煞車把 ×100
煞車線 ×100
煞車器 ×100
```

因此虛件號只是 BOM 的一個管理節點。

---

## 虛件號與半成品比較

| 項目    | 虛件號    | 半成品        |
| ----- | ------ | ---------- |
| 有品號   | ✅      | ✅          |
| 有 BOM | ✅      | ✅          |
| 建立工單  | ❌      | ✅          |
| 入庫    | ❌      | ✅          |
| 有庫存   | ❌      | ✅          |
| MRP   | 直接展開子件 | 先規劃半成品，再展開 |

---

## 適用情境

* 共用零件組
* 包裝組
* 線材組
* 螺絲包
* 標準模組
* 經常被多個產品共用的 BOM

---

## 不適合使用虛件號

若組件符合以下條件，應建立為真正的半成品：

* 需要先製造完成
* 需要建立工單
* 需要入庫
* 需要品質檢驗
* 需要獨立庫存管理
* 可單獨領料或銷售

---

# 二、關鍵件號（Critical Item）

## 什麼是關鍵件號？

關鍵件號（Critical Item）是 ERP 對重要物料的一種**管理標記（Flag）**。

它代表：

> **此物料對生產、品質、交期或成本具有重大影響，需要特別管理。**

它不是一種新的料件類型，而是一種管理屬性。

---

## 關鍵件的特性

| 項目       | 說明  |
| -------- | --- |
| 有庫存      | 通常有 |
| 建立工單     | 可以  |
| 可採購      | 可以  |
| MRP 正常運算 | 是   |
| 重點管理     | 是   |

---

## 哪些物料可能是關鍵件？

腳踏車工廠：

| 物料   | 是否為關鍵件 |
| ---- | ------ |
| 車架   | ✅      |
| 煞車系統 | ✅      |
| 車輪   | ✅      |
| 座墊   | ❌      |
| 貼紙   | ❌      |
| 一般螺絲 | ❌      |

原因：

* 缺少車架，整台車無法生產。
* 煞車品質影響安全。
* 車輪缺料會導致停線。

因此會被列為關鍵件。

---

## ERP 如何使用關鍵件？

### 1. MRP 缺料管理

ERP 可優先提醒：

```text
缺少關鍵件：
FRAME-001
BRAKE-001
```

讓生管優先處理。

---

### 2. 採購管理

長交期物料：

```text
FRAME-001

Lead Time：45 天
```

ERP 可每日追蹤交期，提醒採購催料。

---

### 3. 生產排程

若關鍵件缺料：

```text
車架：有
煞車：有
輪胎：缺
```

排程系統可能禁止工單開工，避免做到一半停線。

---

### 4. 安全庫存管理

ERP 可設定：

```text
FRAME-001

安全庫存：200 PCS
```

當低於安全庫存時，自動預警。

---

### 5. 品質管理

關鍵件通常需要：

* IQC 進料檢驗
* Lot 批號管理
* 序號追蹤
* 出貨追溯

降低品質風險。

---

## ERP 資料表範例

```text
ItemMaster

ItemCode      CriticalFlag
FRAME-001          Y
BRAKE-001          Y
SEAT-001           N
STICKER-001        N
```

# 三、虛件號與關鍵件號比較

| 比較項目  | 虛件號（Phantom） | 關鍵件號（Critical Item） |
| ----- | ------------ | ------------------- |
| 本質    | BOM 結構管理     | 重要物料管理              |
| 有實體物料 | ❌            | ✅                   |
| 有庫存   | ❌            | ✅                   |
| 建立工單  | ❌            | ✅                   |
| 入庫    | ❌            | ✅                   |
| MRP   | 直接展開子件       | 正常運算並重點監控           |
| 採購    | 不採購          | 可採購                 |
| 品質管理  | 不需要          | 通常需要                |
| 主要目的  | 簡化 BOM 維護    | 確保重要物料供應與品質         |

# 四、Bike Factory ERP Demo 範例

## 虛件號

```text
BIKE-001
│
├─ FRAME-001
├─ PH-WHEEL-SET
│   ├─ RIM
│   ├─ TIRE
│   ├─ HUB
│   └─ SPOKE
│
├─ PH-BRAKE-SET
│   ├─ BRAKE LEVER
│   ├─ BRAKE CABLE
│   └─ BRAKE CALIPER
│
└─ SEAT
```

MRP 會直接展開 PH-WHEEL-SET 與 PH-BRAKE-SET 的子件，不會建立工單或庫存。

---

## 關鍵件

```text
ItemMaster

FRAME-001     Critical = Y
BRAKE-001     Critical = Y
TIRE-001      Critical = Y
SEAT-001      Critical = N
STICKER-001   Critical = N
```

ERP 可利用此設定：

* MRP 缺料預警
* 採購催料
* 安全庫存監控
* 品質追蹤
* 生產排程限制

---

# 五、學習重點整理

## 虛件號（Phantom Item）

* 是 BOM 的邏輯群組。
* 不建立工單、不入庫、不管理庫存。
* MRP 會直接展開所有子件。
* 主要目的為降低 BOM 維護成本，提高共用零件管理效率。

---

## 關鍵件號（Critical Item）

* 是 ERP 對重要物料的管理標記。
* 影響採購、生產、MRP、品質與交期管理。
* 通常搭配安全庫存、交期追蹤、IQC 檢驗及缺料預警使用。
* 有助於降低停線風險，提升供應鏈管理效率。

---

## 本章一句話總結

> **虛件號是為了「管理 BOM 結構」；關鍵件號是為了「管理重要物料」。兩者用途完全不同，但都是 ERP 製造管理中非常重要的設定。**
